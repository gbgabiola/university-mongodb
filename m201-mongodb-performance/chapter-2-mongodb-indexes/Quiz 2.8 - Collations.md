# Collations

## Problem:
Which of the following statements are true regarding collations on indexes?

## Check all answers that apply:
1. MongoDB only allows collations to be defined at collection level
2. Collations allow the creation of case insensitive indexes
3. Creating an index with a different collation from the base collection implies overriding the base collection collation.
4. We can define specific collations in an index

## Answer:
2. Collations allow the creation of case insensitive indexes
4. We can define specific collations in an index
