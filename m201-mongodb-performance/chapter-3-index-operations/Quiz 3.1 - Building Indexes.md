# Building Indexes

## Problem:
Which of the following are true of index build operations?

## Check all answers that apply:
1. Foreground index builds block all reads and writes to the collection being indexed.
2. Foreground index builds block all reads and writes to the database that holds the collection being indexed.
3. Background index builds do not impact the query performance of the MongoDB deployment while running.
4. Background index builds take longer to complete than foreground index builds.
5. Background index builds block reads and writes to the collection being indexed.

## Answer:
1. Foreground index builds block all reads and writes to the collection being indexed.
2. Foreground index builds block all reads and writes to the database that holds the collection being indexed.
4. Background index builds take longer to complete than foreground index builds.
