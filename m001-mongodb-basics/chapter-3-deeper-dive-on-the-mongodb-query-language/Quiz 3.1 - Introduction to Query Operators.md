# Introduction to Query Operators

## Problem:
For which CRUD operations can one use the query operators we will discuss in this chapter?

## Check all that apply:
1. Create
2. Read
3. Update
4. Delete

## Answer:
1. Create
2. Read
3. Update
4. Delete

## Detailed Answer:
Given that upserts are a form of create operation, all CRUD operations can make use of a filter. The query operators we are going to discuss in this chapter are used in filters.
