# Final Exam: Question 2

## Problem:
Connect to our class Atlas cluster from Compass and view the **100YWeatherSmall.data** collection. Using the Schema view, explore the **wind** field. The **wind** field has the value type of **document**. Which of the following best describes the schema of this embedded document?

## Choose the best answer:
1. Three fields -- two with the value type "string", one with the value type of "int32"
2. Two fields -- one field with the value type "string", one with a value type of "document"
3. Three fields -- all with the value type "document"
4. Two fields -- both with the value type "document"
5. Three fields -- two with the value type "document", one with the value type "string"

## Answer:
5. Three fields -- two with the value type "document", one with the value type "string"
