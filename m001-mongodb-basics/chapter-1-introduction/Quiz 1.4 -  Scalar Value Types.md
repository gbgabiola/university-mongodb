# Documents: Scalar Value Types

## Problem:
Based on the field depicted below, which of the following are true?

![Year](https://s3.amazonaws.com/edu-static.mongodb.com/lessons/M001/scalar_values_video_year_field.png)

## Check all that apply:
1. Not all documents in this collection have the same value type for this field.
2. Most of the documents in this collection contain int32 values for this field.
3. Some documents in this field have the value type Year

## Answer:
1. Not all documents in this collection have the same value type for this field.
2. Most of the documents in this collection contain int32 values for this field.

## Detailed Answer:
n order to understand the correct answer for this quiz, it is necessary to be able to interpret the information provided for a field in the Compass schema view as outlined in the preceding lesson video. Based on the Compass schema view, there are two value types found in documents for this field: **int32** and **String**. The label "Year" indicates the name of the field, not a data type.
