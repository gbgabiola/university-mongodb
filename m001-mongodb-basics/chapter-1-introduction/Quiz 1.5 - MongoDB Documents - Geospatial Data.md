# MongoDB Documents: Geospatial Data

## Problem:
Which of the following are types of data Compass (and MongoDB) recognizes and specifically supports?

## Check all that apply:
1. documents
2. arrays
3. geospatial data
4. rainfall
5. air pressure

## Answer:
1. documents
2. arrays
3. geospatial data

## Detailed Answer:
As is evidenced by the Compass user interface, MongoDB provides specific support for documents, arrays, and geospatial data. Rainfall and air pressure may be represented as decimal, integer, or other types of vaues, but neither Compass nor MongoDB recognize any type of weather data in order to provide specialized support.
