# Understanding JSON

## Problem
Which of the following data types are directly supported by JSON per the JSON spec?

## Check all that apply:
1. String
2. Array
3. Object
4. Boolean values (true and false)
5. Floating-point number
6. Null
7. Pointer
8. Date
9. Graph
10. Decimal number

## Answer:
1. String
2. Array
3. Object
4. Boolean values (true and false)
5. Floating-point number
6. Null

## Detailed Answer:
Please review the [JSON spec](http://www.json.org/) if you are struggling with which data types are directly supported in JSON.
