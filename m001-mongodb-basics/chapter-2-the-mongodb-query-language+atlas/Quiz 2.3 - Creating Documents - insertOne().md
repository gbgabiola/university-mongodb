# Creating Documents: insertOne()

## Problem:
Which of the following statements are true of creating documents in MongoDB?

## Check all answers that apply:
1. Both the mango shell and Compass support the ability to insert single documents.
2. _id values created for us by MongoDB are of type int32.
3. All _id values within a single collection must be unique.
4. MongoDB or the client will create an _id for us if we do not supply one.
5. We can supply an _id for the document.

## Answer:
1. Both the mango shell and Compass support the ability to insert single documents.
3. All _id values within a single collection must be unique.
4. MongoDB or the client will create an _id for us if we do not supply one.
5. We can supply an _id for the document.

## Detailed Answer:
_id values created for us by MongoDB are of type **ObjectId** not **int32**. The rest of the statements are true and either mentioned or illustrated in the preceding lesson video.
